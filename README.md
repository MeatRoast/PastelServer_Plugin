# Pastel Minecraft Plugins

디스코드 파스텔 서버에서 운영하는 마인크래프트 Paper 서버용 플러그인 모음입니다.

이 저장소에는 서버 운영에 필요한 데이터베이스 연동, 채팅, 길드, 경제, 퀘스트, 서버 메뉴 기능을 담당하는 플러그인들이 포함되어 있습니다.

## 플러그인 목록

### SQLDB

여러 플러그인이 함께 사용할 수 있는 MySQL 연결 서비스 플러그인입니다.

- Paper 플러그인에서 공통으로 사용할 데이터베이스 연결 제공
- `/dbping` 명령어로 MySQL 연결 상태 확인
- `/dbsql` 명령어로 연결 재시작, 중지, 테이블 확인 등 관리 기능 제공

### CrossChat

서버 채팅 기능을 관리하는 플러그인입니다.

- 전체 채팅, 서버 채팅, 지역 채팅 등 채팅 모드 관리
- 플레이어 닉네임 색상 변경 기능
- 채팅 관련 아이템 지급 기능
- SQLDB와 연동하여 채팅 관련 데이터를 관리

### Guild

플레이어 길드 시스템을 제공하는 플러그인입니다.

- 길드 생성 및 관리 기능
- 길드원 정보와 길드 프로필 관리
- `/guild`, `/길드` 명령어 지원
- SQLDB와 연동하여 길드 데이터를 저장

### Money

서버 경제 시스템을 담당하는 플러그인입니다.

- 플레이어 돈 데이터 관리
- 다른 플러그인에서 사용할 수 있는 경제 서비스 제공
- 관리자 권한 기반 경제 관리 기능
- SQLDB와 연동하여 경제 데이터를 저장

### QuestPlugin

서버 퀘스트 시스템을 제공하는 플러그인입니다.

- `/quest` 명령어로 퀘스트 목록 확인
- `/questadmin` 명령어로 퀘스트 리로드, 일일 초기화, 길드 퀘스트 설정 관리
- 일반 퀘스트와 관리자용 퀘스트 관리 기능 제공

### MemuServerMenu

서버 선택 GUI를 제공하는 메뉴 플러그인입니다.

- `/servermenu` 명령어로 서버 선택 메뉴 열기
- 서버 이동용 GUI 제공
- PlaceholderAPI와 연동 가능
- SQLDB와 연동하여 서버 메뉴 관련 상태를 관리
